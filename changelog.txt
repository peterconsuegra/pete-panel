Version 15.5 – 2026-10
------------------------------------------------------------------
- 🔒 SSL certificates renew themselves 30 days before they expire: the panel records each
  certificate's expiry when it is issued and checks every site with SSL daily at 03:00
  (sites:renew-ssl); a failed renewal is retried the next day.
- Fixed: the renewal no longer waits 360 days (Let's Encrypt certificates last 90) and never
  turns SSL on for sites that don't use it.
- Security: generating SSL no longer writes the Apache secret to the log or returns it to the
  browser.
- Needs the Laravel scheduler running: Pete Docker images built from 2026-10-14 run it (earlier
  images skipped it).

Version 13.0 – 2025-09
------------------------------------------------------------------
- 🚀 Major release with Laravel 10.x core upgrade (PHP 8.3 support).
- Improved integration between WordPress and Laravel with one-click setup.
- Added enhanced Admin security tools with OWASP CRS integration.
- New backup restore/download flows under `/backups` routes.
- Built-in SSL generator integrated with Let’s Encrypt.
- Performance tuning: Apache MPM Event, HTTP/2 support by default.
- Improved UI layout with Bootstrap 5.3, sidebar refinements, and toast notifications.
- Extended Gate policies for sites and backups (admin/owner rules).
- Enhanced unauthorized access logging for better audit trails.

Version 12.0 – 2025-06
------------------------------------------------------------------
- Introduced PeteOption & PeteService singletons for cleaner app-wide caching.
- Added global view composers (sidebar options, dashboard URL).
- Integrated system variables (options) CRUD with full auth & gate checks.
- Cache invalidation on Option model save/delete events.
- New plugin management endpoints:
  • Install, uninstall, update plugins via `/plugins` prefix.
- Added server status & toggle actions in Admin routes.
- PHPMyAdmin panel and toggle endpoint included.
